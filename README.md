# Ligne du temps de l'histoire de l'art

Cette ligne du temps est une frise chronologique interactive qui permet d'explorer différentes oeuvres et des mouvements artistiques de la Préhistoire jusqu'à aujourd'hui.

## La ligne du temps

La ligne du temps couvre une période allant de la Préhistoire à aujourd'hui.
Cliquer sur un mouvement ou une période artistique vous mène à une page sur le mouvement en question, avec une description et une galerie d'oeuvres célèbres du mouvement.
Cliquer sur une oeuvre vous mène à une page descriptive de l'oeuvre, avec plusieurs informations à son sujet et un outil pour agrandir l'oeuvre en haute définition.


Je m’intéresse beaucoup à l’art et à l’histoire, notamment à la façon dont l'art a évolué au cours de l'histoire. Je voulais créer une façon visuelle et interactive d’explorer les différents mouvements et courants artistiques.

## Technologies

* Next.js
* React
* TypeScript
* Tailwind CSS

## Installation

```bash
git clone https://github.com/TetreaultF/art-timeline.git
cd art-timeline
npm install
npm run dev
```
Le projet est accessible à `http://localhost:3000`.
